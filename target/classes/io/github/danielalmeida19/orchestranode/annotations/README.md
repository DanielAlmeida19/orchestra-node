# Annotations Module

***

Este módulo funciona como um declarador de anotações para que seja possível criar as modificações que o _OrchestraNode_ aceita em sua composição a nível de classe.
Dessa forma, é possível definir quais são os atributos mapeados e o _OrchestraNode_ reconhecerá a diferença entre os esquemas mapeados quando houver.
